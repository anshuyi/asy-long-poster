# 拼接规则

v2.2 优先规则：自然过渡项目先做实际预览，按观看效果验收；下面旧试验的锚点匹配仅适用于需要结构连续或选择直接衔接的情况。羽化仍不负责改字、重建主体或修复含义错误。

方法选择：直接匹配用 none；安全区可裁用裁切；背景/纹理细微差异用 feather；选择性保留用 mask；允许装饰渐隐且背景简单可用 haze。不要机械走完所有方法。每对接缝保留原尺寸与阅读宽度检查。

haze 仅用于 natural + replaceable_background + schema 1.1。参数：overlap_px、feather_px、haze_strength（0..1）、background_rgb、background_reviewed=true、background_samples（upper/lower 两组原图坐标框）。可选 haze_mask_path/haze_mask_sha256 是 W×overlap 的 L 遮罩，255 表示允许雾化。仍禁止整个融合带触碰保护框。

背景采样先目视确认干净。程序拒绝采样跨保护框或融合带，拒绝单通道95%与5%分位差大于24、两侧中位色差大于24、指定颜色与采样均色相差大于8的候选。它们是当前保守的预检阈值，不能自动证明背景语义正确。复杂纹理/强渐变需要别的方法。

雾化在普通羽化上叠加中心较强、两端归零的背景色，默认不额外增加图高。强度越大不代表越好，出现平滑横带就降低强度或改用其他方案。预览与正式合成共用 blend_region/render_canvas，正式方案必须匹配已审阅的图像版本、保护框、两侧切口及融合参数。

读取 execution-contract.md 的 20.3—20.4 和实际相邻图。直接接续不等于共享重叠，羽化不能修复错字、双影或主体错位。使用当前版本的全宽 crop_box；方法 none/hard/feather/mask 按实图选择，可相同。所有保护框必须在裁后区域内且不进入融合带。先 project_state.py plan，再 stitch_images.py，脚本拒绝无效参数。

真实试验规则：原始上下边界不匹配时，先检查各自允许裁切的连接带内是否存在自然匹配位置。记录该位置的锚点、边界偏差、保护框距离，再生成接缝局部预览。只有安全裁切后仍有台阶、错位或主体损坏时才返工；不能把羽化当作形状修复器。验收写“裁切后可衔接”，不得把它改说成“生成工具精确锁定了原始边界”。
